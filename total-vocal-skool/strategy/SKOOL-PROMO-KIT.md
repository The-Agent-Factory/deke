from reach to membership is.**

## 1. The branded tag system

Three tiers. Every post uses tier 1. Tiers 2 and 3 are drawn from as the content fits.

### Tier 1 — Ownership tags (ALWAYS, every post, every platform)

```
#TotalVocal #DekeSharon
```

These two are non-negotiable and already have equity (21 and 30 prior uses). They are how
the back-catalog stays searchable as one body of work.

### Tier 2 — Community tags (the new layer — this is what was missing)

```
#TotalVocalCommunity   ← the "there is a place to go" tag; use on any post with a CTA
#SingWithDeke          ← invitational, works as a spoken CTA too ("come sing with me")
#TotalVocalSkool       ← literal, for posts that explicitly name the platform
```

**Rule:** at least **one** tier-2 tag on every post that carries a Skool CTA. Use
`#TotalVocalCommunity` as the default; it is the most legible to someone who has never
heard of Skool.

> ⚠️ **These three tags are new as of 2026-08-29.** They have no prior reach. That is the
> point — they become the searchable home for community content. Expect zero discovery
> value for the first ~30 posts; their value is consistency and retargeting, not reach.
> Discovery comes from tier 3.

### Tier 3 — Discovery tags (rotate by topic, this is where reach comes from)

Pull 6–10 per post from the pool that matches the content. These are the proven performers
already in use across the project:

| Cluster | Tags |
|---|---|
| **Core craft** | `#acappella` `#vocalharmony` `#contemporaryacappella` `#vocalmusic` `#harmony` `#singing` |
| **Practitioner** | `#vocalcoach` `#choirdirector` `#choir` `#singtogether` `#singerslife` |
| **Technique** | `#beatbox` `#vocalpercussion` `#vocaltricks` `#arranging` `#improv` |
| **Event / place** | `#acappellafestival` `#croappella` `#klapa` (+ city/country tags as earned) |
| **Reach** | `#fyp` (TikTok only) `#Shorts` (YouTube Shorts only) |

**Do not invent event or place tags.** Only use ones verified against the source material —
same rule as the copy masters' publisher notes.

## 2. Per-platform tag recipe

Tag counts and placement differ by platform. These are the specs to build to.

### Instagram / Facebook
- **Count:** 10–15 total (2 tier-1 + 1–2 tier-2 + 7–11 tier-3)
- **Placement:** after three dot-separated line breaks, below the caption body (the existing
  copy masters already do this — keep it)
- **CTA:** in the caption body, **not** buried in the tag block. See §3.

```
.
.
#acappella #vocalharmony #dekesharon #totalvocal #totalvocalcommunity #vocalcoach
#contemporaryacappella #choirdirector #singtogether #vocalmusic #harmony #singing
```

### TikTok
- **Count:** 5–7 (TikTok's algorithm reads the caption, not a tag wall)
- **Must include:** `#fyp` and one tier-2 tag
- **Placement:** inline in the caption, at the end

```
#acappella #dekesharon #totalvocal #singwithdeke #vocalcoach #fyp
```

### YouTube Shorts
- **Count:** 3–5 in the description, plus `#Shorts`
- **Also fill the tags field** — that is a separate system; run the `youtube-tags` skill for
  the transcript-derived tag string. Hashtags ≠ YouTube tags.

```
#Shorts #acappella #dekesharon #totalvocal
```

### LinkedIn
- **Count:** 3–5 maximum. More reads as spam to this audience.
- **Angle:** professional/pedagogical framing

```
#acappella #musiceducation #vocalcoach #totalvocal
```

### Threads / X
- **Count:** 2–3. Conversational platforms; tags are near-decorative.

```
#acappella #totalvocal
```

## 3. The CTA system (this is the part that actually moves members)

A hashtag does not produce a click. The link path does. Every post gets **one** CTA,
matched to what the platform allows.

### The CTA ladder — pick by post type

| Post type | CTA | Why |
|---|---|---|
| **Teaching / technique reel** | *"Try it and post your clip in the community — I listen to every one."* → `skool.com/deke` | Highest converting. Gives a reason to join that only membership satisfies. This line already exists in the CROappella Skool post — it belongs in the **public** caption instead. |
| **Event / BTS reel** | *"More of this, and the full session, at skool.com/deke"* | Implies there is more behind the door |
| **Quote / text post** | *"We go deeper on this every week → skool.com/deke"* | Low-friction |
| **Live event announce** | *"Free — join at skool.com/deke, the event's on the community calendar."* | Proven; this is the AMA pack's line, the one pack that did it right |

**One CTA per post. Never two.** Competing asks convert worse than a single clear one.

### Platform link mechanics

| Platform | How the link actually works | Action required |
|---|---|---|
| **Instagram** | Captions are not clickable. Bio points to `linktr.ee/dekesharon` -> 13 links. **VERIFIED 2026-08-29: no Skool link exists there.** | BLOCKER: fix the Linktree first (see below). Then caption CTA says **"link in bio"** *and* speaks the URL |
| **IG Stories** | Link sticker is clickable | Use a link sticker on every Story that mentions the community |
| **TikTok** | Bio link only (clickable at 1k+ followers — **TikTok is at 47, so it is NOT clickable yet**) | Speak the URL in caption + on-screen text. Do not write "link in bio" on TikTok until it earns the feature. |
| **Facebook** | Captions clickable | Full URL: `https://www.skool.com/deke/about` |
| **YouTube** | Description clickable | Pin the link in the description **and** the first pinned comment |
| **LinkedIn** | Clickable, but links in-post suppress reach | Put the link in the **first comment**, and say "link in the comments" |
| **Threads / X** | Clickable | Full URL inline |

**The Instagram double-path (important):** because IG captions are dead links, always write
the URL out loud *and* point at the bio. Someone reading on a phone will type it; someone
browsing will tap the bio. Costs nothing, captures both.

> Example: `Come sing with us → skool.com/deke (link in bio)`

### On-screen text on reels

The most underused conversion surface. Every vertical reel gets an end card, last 2–3
seconds, matching the existing brand gold (`#D8A33E` / `#D4A853`):

```
skool.com/deke
```

That is it. No logo animation, no "subscribe." One line, high contrast, held long enough
to read twice. This works on every platform simultaneously and survives cross-posting.

Carried forward from the copy masters' publisher notes, because it has real legal weight:

✅ **Safe to tag:** official festival/organization accounts that are verifiable —
`@croappella`, host groups as organizations, venues **only when confirmed**.

body** (as CROappella already does with A.K.A. Crescendo, Matea, Jakov) and tag only the
